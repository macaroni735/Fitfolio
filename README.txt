Fitfolio gives users the full power of their own personal wardrobe entirely in the palm of their hand!

Application Setup:
    Ensure python is installed for creating a virtual environment,
    Within Fitfolio root, create a python virtual environment:
        bash: "python -m venv .venv"
    Activate the environment:
        bash: "source .venv/Scripts/activate"
    Install dependencies:
        bash: "pip install -r requirements.txt"
